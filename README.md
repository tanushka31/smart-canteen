\# Smart Canteen 🍴



A full-stack campus food ordering system designed to make college canteen ordering faster, easier, and more convenient.



\## ✨ Features



\- 🔐 Student Login \& Sign Up

\- 🍔 Browse Canteen Menu

\- 🔎 Search Food Items

\- 🛒 Add Items to Cart

\- 💳 Checkout \& Order Placement

\- 📍 Pickup Location Selection

\- 📋 View \& Track Orders

\- 📦 Real-Time Inventory Management

\- 👨‍💼 Admin Dashboard

\- 📊 Admin Order Management

\- 🔄 Order Status Updates

\- 🛡️ Stock Availability Protection

\- 💾 MongoDB Database



\## 🛠️ Technologies Used



\### Frontend

\- React

\- Vite

\- CSS



\### Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT Authentication

\- bcrypt.js
